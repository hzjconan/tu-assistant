# 学习文档：从零做一个法律领域的自训模型

这套文档伴随 tu-assistant POC 的实施逐章编写，记录**做了什么、为什么这么做、背后的原理、实际结果和踩过的坑**。
所有命令、日志和数字都来自本项目真实运行的结果。

## 阅读顺序

| 章节 | 内容 | 状态 |
|---|---|---|
| [00 术语表](./00-glossary.md) | 常用术语速查，每个术语链接到详细讲解 | 持续补充 |
| [01 全局视角](./01-big-picture.md) | 微调 vs RAG；本项目的技术路线；POC 与正式阶段 | ✅ |
| [02 硬件与环境](./02-hardware.md) | Mac 为什么能训练；本机实测数据怎么读；内存花在哪里 | ✅ |
| 03 知识库 | 法律文本结构、条款切分、出处校验层 | P0 完成后 |
| 04 训练数据 | 训练数据长什么样、为什么要改写成问答、数据合成、评测与训练隔离 | P1 完成后 |

| 08 复盘 | 踩坑汇总；POC 说明了什么、没说明什么；正式阶段要做什么 | POC 结束时 |

## 怎么提问

每个知识点都有编号，格式为 `[L章.节]`，例如 `[L2.3]` 表示第 2 章第 3 节。

- 想深入某一点：直接说"展开讲讲 L2.3"。
- 讲解之后如果值得保留，会补充回对应章节。
- 每章末尾有"可以继续问的问题"，列出值得深入的方向。

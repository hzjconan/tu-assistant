# 00 术语表

按主题分组。每个术语给出一句话解释，并链接到详细讲解的章节。随着 POC 推进持续补充。

## 模型基础

| 术语 | 解释 | 详见 |
|---|---|---|
| 大语言模型（LLM） | 根据前文预测下一个 token 的模型，循环预测即可生成文字 | [L1.1](./01-big-picture.md#l11-大模型是什么) |
| token | 模型读写文字的最小单位；中文约 1–2 个字一个 token | [L1.1](./01-big-picture.md#l11-大模型是什么) |
| 参数 / 权重 | 模型内部的数字，"7B"指约 70 亿个参数；训练就是调整它们 | [L1.1](./01-big-picture.md#l11-大模型是什么) |
| 基座模型 | 厂商预训练好的通用模型，本项目在它的基础上微调 | [L1.1](./01-big-picture.md#l11-大模型是什么) |
| 预训练 | 用海量通用文本训练出基座模型的过程 | [L1.1](./01-big-picture.md#l11-大模型是什么) |
| 词表 | 模型认识的全部 token 的集合；Qwen2.5 约 15 万，Qwen3.5 约 24.8 万 | [L2.7](./02-hardware.md#l27-为什么长样本特别吃内存) |
| 上下文 | 模型一次能"看到"的全部输入文字 | [L1.2](./01-big-picture.md#l12-让模型掌握私有知识的三种方式) |

## 让模型掌握知识的方式

| 术语 | 解释 | 详见 |
|---|---|---|
| RAG（检索增强生成） | 先检索相关文档，再交给模型回答 | [L1.2](./01-big-picture.md#l12-让模型掌握私有知识的三种方式) |
| 微调 | 用自己的数据继续训练基座模型，改变它的参数 | [L1.2](./01-big-picture.md#l12-让模型掌握私有知识的三种方式) |
| CPT（继续预训练） | 用大段纯文本微调，主要教知识 | [L1.3](./01-big-picture.md#l13-微调的几种形式) |
| SFT（指令微调） | 用"问题 → 标准回答"的对话微调，主要教行为 | [L1.3](./01-big-picture.md#l13-微调的几种形式) |
| DPO（偏好优化） | 用"好回答 / 坏回答"成对的数据微调，教模型少犯某类错误 | [L1.3](./01-big-picture.md#l13-微调的几种形式) |
| 出处校验层 | 按条款编号查条款库、核对并纠正模型引用的程序（不是模型） | [L1.6](./01-big-picture.md#l16-出处校验层给模型的记忆兜底) |

## 训练技术

| 术语 | 解释 | 详见 |
|---|---|---|
| 全参数微调 | 更新模型的全部参数；效果上限高，内存需求极大 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 梯度 | 每个参数应该朝哪个方向调整、调整多少 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 优化器（Adam） | 根据梯度更新参数的算法，为每个参数额外保存历史状态 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 激活值 | 前向计算的中间结果，大小与样本长度成正比 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 量化 / 4bit | 用更少的位数存储参数；4bit 让 7B 权重从约 14GB 降到约 4.4GB | [L2.2](./02-hardware.md#l22-精度与量化4bit-是什么) |
| FP16 / BF16 | 每个参数用 16 位存储的两种格式，GPU 训练常用 | [L2.2](./02-hardware.md#l22-精度与量化4bit-是什么) |
| LoRA | 冻结原权重，只训练旁路的两个小矩阵 | [L2.3](./02-hardware.md#l23-lora只训练一小部分参数) |
| rank（秩） | LoRA 小矩阵的宽度，越大能学的越多、占用越多 | [L2.3](./02-hardware.md#l23-lora只训练一小部分参数) |
| 适配器（adapter） | LoRA 训练的产物，几十 MB，可与基座合并或单独加载 | [L2.3](./02-hardware.md#l23-lora只训练一小部分参数) |
| QLoRA | 4bit 量化的基座 + LoRA，消费级硬件的标准微调方式 | [L2.4](./02-hardware.md#l24-qlora--4bit-量化--lora) |
| 梯度检查点 | 少存中间结果、需要时重算，用约 14% 的速度换一半内存 | [L2.8](./02-hardware.md#l28-梯度检查点用时间换内存) |
| epoch（轮） | 把全部训练数据完整过一遍 | [L2.9](./02-hardware.md#l29-怎么估算训练时间) |
| loss | 模型预测的错误程度，训练中下降表示在学习 | [L2.6](./02-hardware.md#l26-本机实测数据怎么读)；第 05 章详解 |
| 最大序列长度 | 单个样本允许的最大 token 数，超出部分被截断 | [L2.6](./02-hardware.md#l26-本机实测数据怎么读) |
| 超参数 | 训练前人为设定的参数（rank、学习率、轮数等），区别于模型自己学到的参数 | 第 05 章 |

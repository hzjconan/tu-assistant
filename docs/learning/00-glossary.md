## 训练技术

| 术语 | 解释 | 详见 |
|---|---|---|
| 全参数微调 | 更新模型的全部参数；效果上限高，内存需求极大 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 梯度 | 每个参数应该朝哪个方向调整、调整多少 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 优化器（Adam） | 根据梯度更新参数的算法，为每个参数额外保存历史状态 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 激活值 | 前向计算的中间结果，大小与样本长度成正比 | [L2.1](./02-hardware.md#l21-训练时内存花在哪里) |
| 量化 / 4bit | 用更少的位数存储参数；4bit 让 7B 权重从约 14GB 降到约 4.4GB | [L2.2](./02-hardware.md#l22-精度与量化4bit-是什么) |
| FP16 / BF16 | 每个参数用 16 位存储的两种格式，GPU 训练常用 | [L2.2](./02-hardware.md#l22-精度与量化4bit-是什么) |
| LoRA | 冻结原权重，只训练旁路的两个小矩阵 | [L2.3](./02-hardware.md#l23-lora只训练一小部分参数) |
| rank（秩） | LoRA 小矩阵的宽度，越大能学的越多、占用越多 | [L2.3](./02-hardware.md#l23-lora只训练一小部分参数) |
| 适配器（adapter） | LoRA 训练的产物，几十 MB，可与基座合并或单独加载 | [L2.3](./02-hardware.md#l23-lora只训练一小部分参数) |
| QLoRA | 4bit 量化的基座 + LoRA，消费级硬件的标准微调方式 | [L2.4](./02-hardware.md#l24-qlora--4bit-量化--lora) |
| 梯度检查点 | 少存中间结果、需要时重算，用约 14% 的速度换一半内存 | [L2.8](./02-hardware.md#l28-梯度检查点用时间换内存) |
| epoch（轮） | 把全部训练数据完整过一遍 | [L2.9](./02-hardware.md#l29-怎么估算训练时间) |
| loss | 模型预测的错误程度，训练中下降表示在学习 | [L2.6](./02-hardware.md#l26-本机实测数据怎么读)；[L5.3](./05-training.md#l53-看懂-loss-曲线) |
| 最大序列长度 | 单个样本允许的最大 token 数，超出部分被截断 | [L2.6](./02-hardware.md#l26-本机实测数据怎么读) |
| 超参数 | 训练前人为设定的参数（rank、学习率、轮数等），区别于模型自己学到的参数 | [L5.2](./05-training.md#l52-超参数逐项解释) |
| iteration（步） | 处理一个 batch 并更新一次参数；batch=1 时一步即一条样本 | [L5.1](./05-training.md#l51-一次训练的全过程) |
| batch size | 每步同时喂给模型的样本数 | [L5.2](./05-training.md#l52-超参数逐项解释) |
| 学习率 | 每步参数调整的幅度；最敏感的超参数 | [L5.2](./05-training.md#l52-超参数逐项解释) |
| LoRA scale / alpha | LoRA 旁路输出的放大系数；PEFT 用 alpha/rank，mlx_lm 只认 scale（alpha 不生效） | [L5.2](./05-training.md#l52-超参数逐项解释) |
| num_layers | 给模型最后多少层挂 LoRA（-1 表示全部层） | [L5.2](./05-training.md#l52-超参数逐项解释) |
| dropout | 训练时随机丢弃部分输出以防过拟合 | [L5.2](./05-training.md#l52-超参数逐项解释) |
| mask_prompt | loss 是否只计算 assistant 回答部分；mlx_lm 默认否 | [L5.2](./05-training.md#l52-超参数逐项解释) |
| train loss / val loss | 在训练样本 / 未训练过的验证样本上的 loss；后者衡量能否推广 | [L5.3](./05-training.md#l53-看懂-loss-曲线) |
| teacher forcing | 算 loss 时总给模型喂标准前文；与真实生成时"接着自己写"不同 | [L5.4](./05-training.md#l54-loss-降了--效果好本次就是反例) |
| 训练/推理分布不一致 | 运行时输入的形态（如是否带 system prompt）与训练数据不同，导致训练效果用不上 | [L5.4](./05-training.md#l54-loss-降了--效果好本次就是反例) |
| 冒烟评测 | 训练早期用少量真实评测题快速检查输出是否正常 | [L5.4](./05-training.md#l54-loss-降了--效果好本次就是反例) |
| 过拟合 / 欠拟合 | 死记训练集、对新样本变差 / 还没学够 | [L5.5](./05-training.md#l55-过拟合与欠拟合) |
| 容量 | 模型参数能装下的知识与能力，随规模增长 | [L5.6](./05-training.md#l56-模型规模与容量) |

## 训练数据

| 术语 | 解释 | 详见 |
|---|---|---|
| 样本 | 一条训练输入，本项目统一写成 `messages` 对话 | [L4.4](./04-training-data.md#l44-四类样本与产出格式) |
| meta | 生成侧记录的溯源信息，不进提示词、不进训练文件 | [L4.4](./04-training-data.md#l44-四类样本与产出格式) |
| rewrite_factor | 每条条款让外部模型改写几种问法 | [L4.3](./04-training-data.md#l43-一次调用长什么样) |
| train / valid | 训练集 / 验证集；本项目按 9:1 切分 | [L4.6](./04-training-data.md#l46-数据集落地) |
| 过采样 | 在训练集中重复少数类样本，提高行为信号占比；只作用 train | [L4.7](./04-training-data.md#l47-当前数据集的真实结果) |
| manifest | 产物清单，记录输入版本、配置、种子和数量 | [L4.6](./04-training-data.md#l46-数据集落地) |
| citation_missing | 训练样本里完全解析不到有效引用时的丢弃原因 | [L4.5](./04-training-data.md#l45-质量关卡坏样本不许进训练集) |
| 整条按款展开 | 责任条款引用整条多款条文时，按该条各款拆成逐款候选，由人工剔除总则/宣示性款 | [L3.4.1](./03-knowledge-base.md#l341-条与款的定位粒度抽取审阅与校验如何联动) |
| 兼容款级回退 | 多款条文未写款号但引文逐字唯一匹配某款时，校验层回退到该款并单独计数（口径 C） | [L3.4.1](./03-knowledge-base.md#l341-条与款的定位粒度抽取审阅与校验如何联动) |
| 知识库派生 | 从历史 SQLite 复制生成新版本并只变更编号/关系，保持 `clause_id` 与原文不变且不触碰旧库 | [L3.4.1](./03-knowledge-base.md#l341-条与款的定位粒度抽取审阅与校验如何联动) |
| 分组划分（Group Split） | 把存在派生关系的样本家族（如文章初稿与其全部修改稿）整组划到同一侧（同在 train 或同在 valid） | [L4.5.3](./04-training-data.md#l453-数据集增量更新续训留出集保护与跨请求去重) |
| 数据泄漏（Data Leakage） | 训练集与验证集/评测集存在相同或同源衍生样本，导致验证指标虚高 | [L4.5.3](./04-training-data.md#l453-数据集增量更新续训留出集保护与跨请求去重) |
| 续训验证集污染 | 从已有 checkpoint 续训时重新随机切分旧数据，导致新 valid 混入起点已训过的 train 样本，使 val loss 失真 | [L4.5.3](./04-training-data.md#l453-数据集增量更新续训留出集保护与跨请求去重) |

# T057 执行单 · 文章样本合入数据集

**状态**　记录 T052 复审发现的扩量前置条件，待 T052、T053 交付后补全实施步骤并由用户审阅。

1. **核对素材及责任关系。** 对照 T077 的修正结果，列出本次 KB 版本、确认过的依据/责任 ID 和可合写的纠纷。每种组合用一篇小样说明当事人、事件和两项责任的联系，逐项核对行为主体、适用条件和救济。若只剩“阻挠入会与侵占工会财产”一组，先补经审阅的素材。记录实际使用的组合与频次。
2. **按案例做跨请求去重。** 在训练/验证划分前汇总初稿与修改稿。比较案例段的情节、手段和主体，忽略公共法条引文的天然重复。以 T052 的住宿默认三篇和显式两篇作为已知近重复对照，确认能发现换标题、换姓名但事实高度相似的案例。记录筛除数和人工复核结果，关联初稿与修改稿应归在同一侧。可依法更换主体类型的条款须检验主体差异，同一义务固定落在经营者时检验手段或情节差异。
3. **覆盖自然问法。** 分别抽查“写一篇 / 写两篇”等显式篇数、未指定篇数及“写几篇”等模糊表达。用独立构造的问句确认默认三篇和显式篇数均能对应成稿，记录各类数量。v1 正式题继续只用于本地去重和评测。
4. **交付前留证。** 提交素材覆盖、去重前后分布、问法覆盖和样本位置，标明经内容复核的样本。T052 各批 `samples.jsonl` 包含自动通过后又被人工退回的记录，禁止直接整批并入训练。

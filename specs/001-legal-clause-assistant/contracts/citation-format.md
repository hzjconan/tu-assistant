# Contract: 引用格式与输出结构

模型的输出必须遵守本格式；出处校验层（research R5）与评测打分都依赖它。
训练数据（SFT）按本格式构造。

## 1. 引用标记

每一处具体条款引用写成一个**引用块**：

```markdown
〔《中华人民共和国工会法》（2021年修正）第五十一条第一款〕
> 违反本法规定，……（条款原文）
```

- 标记用全角六角括号 `〔 〕` 包裹，内容依次为：`《文件全称》`、`（版本）`、`第N条`、可选 `第M款`、可选 `第K项`。
- 编号用中文数字或阿拉伯数字均可，解析时统一转为整数。
- 标记下一行起的 Markdown 引用（`> `）为条款原文，可以省略；省略时校验层自动补入知识库原文。
- 正文中再次提到已引用的条款时，必须重复完整标记（可不带原文），不得写"上述第X条"之类的裸引用。

解析正则（参考）：

```text
〔《(?P<title>[^》]+)》（(?P<version>[^）]+)）第(?P<article>[0-9零〇一二三四五六七八九十百千]+)条(?:第(?P<paragraph>[0-9零〇一二三四五六七八九十]+)款)?(?:第(?P<item>[0-9零〇一二三四五六七八九十]+)项)?〕
```

## 2. 校验结果的呈现

| 校验结论 | 交付给用户的内容 |
|---|---|
| `ok` | 原样保留 |
| `corrected` | 原文替换为知识库原文（不提示用户，记录到指标） |
| `not_found` | 删除整个引用块，替换为 `〔此处引用未通过校验，已删除〕` |
| `incomplete` | 正文中的裸引用保留，记录为出处不完整（SC-006 计为失败） |

## 3. 咨询回答结构

```markdown
## 违法行为认定

### 1. <违法主体>：<行为概述>

**适用条款**
〔《…》（…）第N条〕
> …

**适用分析**
……

**法律责任**
〔《…》（…）第N条〕
> …

### 2. …（多个违法行为逐一列出）

## 需要补充确认的事实（如有）
- ……

---
*以上内容仅供参考，不构成法律意见。*
```

- 免责提示由编排层追加，模型不必生成（FR-023）。
- 拒答时不输出上述结构，直接说明不在知识范围内（FR-022）。

## 4. 普法文章结构

```markdown
# <标题>

## 案例
<场景叙述，人物与单位使用虚构名称>

## 以案说法
### <违法主体>：<行为>
**法律依据**
〔《…》（…）第N条〕
> …
**法律责任**
〔…〕
> …

## 普法提示
……
```

一次生成多篇时，每篇以一级标题开始，篇与篇之间用 `---` 分隔。

## 5. 追问

追问轮的输出为编号列表，每个问题一行，以中文问号结尾；问题数不超过 system prompt 中给出的上限：

```markdown
为了准确判断，请补充以下信息：
1. ……？
2. ……？
```
